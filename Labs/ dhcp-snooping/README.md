# DHCP Snooping – Rogue DHCP Mitigation Lab

## Project Overview

This Cisco Packet Tracer lab demonstrates the use of DHCP snooping
as a Layer 2 security control to protect a network from unauthorized
DHCP servers.

The project demonstrates DHCP behavior before and after implementing
DHCP snooping and shows how trusted and untrusted switch interfaces
can be used to control DHCP traffic.
