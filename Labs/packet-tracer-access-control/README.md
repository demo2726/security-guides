# Cisco Packet Tracer – Access Control & RADIUS Lab

## Overview

This project demonstrates the implementation of network access controls
using Cisco Packet Tracer. The lab focused on two security mechanisms:

- Access Control Lists (ACLs)
- RADIUS/AAA authentication

The objective was to configure network security controls, restrict
unauthorized traffic, and implement centralized authentication for
wireless users.

## Technologies Used

- Cisco Packet Tracer
- Cisco 1941 Router
- Cisco 2960 Switches
- Access Control Lists (ACLs)
- RADIUS
- AAA
- WPA2
- IPv4 Networking

## Part 1 – Access Control Lists

I created a network containing a Cisco router, two switches, and four
workstations located on separate networks.

I configured an ACL on the router to control which hosts were allowed
to send traffic through the router interface.

### Skills Demonstrated

- IPv4 addressing
- Router interface configuration
- Standard ACL configuration
- Applying ACLs to interfaces
- Testing network connectivity
- Troubleshooting with ping
- Verifying ACLs with show commands

## Part 2 – RADIUS Authentication

I configured a wireless network using centralized RADIUS
authentication.

The RADIUS server provided AAA services and authenticated wireless
clients before allowing them to connect to the network.

### Skills Demonstrated

- RADIUS configuration
- AAA authentication
- WPA2 wireless security
- Centralized user authentication
- Wireless network configuration
- Authentication troubleshooting

## What I Learned

This lab demonstrated the difference between controlling network
traffic with ACLs and controlling user access through centralized
authentication.

ACLs can restrict traffic based on network addressing and interface
placement, while RADIUS provides centralized authentication for users
attempting to access network resources.
