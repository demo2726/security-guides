### Securing Wi-Fi

1. **Strong Encryption**

   * Always use WPA3 when available.
   * Avoid outdated standards like WEP and WPA2-PSK.

2. **Strong Wi-Fi Passwords**

   * Use complex, unique passphrases (at least 12–16 characters).
   * Rotate/change passwords periodically.

3. **SSID Best Practices**

   * Avoid using personal or identifiable information in SSID.
   * Consider disabling SSID broadcasting for sensitive networks.

4. **Router & Access Point Security**

   * Change default admin credentials.
   * Keep router firmware updated.
   * Disable unnecessary features (e.g., WPS, UPnP, remote admin).

5. **Network Segmentation**

   * Separate IoT devices from the main/home network.
   * Use VLANs or guest networks for isolation.

6. **MAC Address Filtering (Optional)**

   * Adds an extra layer of access control (though not foolproof).

7. **Monitoring & Logging**

   * Monitor connected devices regularly.
   * Enable logging to detect suspicious activity.

8. **Physical Security**

   * Place router in a secure location (not easily accessible).
   * Limit signal range if possible (to avoid external coverage leaks).
